# 0.0.1 支持范围

更新：2026-11-10。已验证宿主为 3ds Max 2026.3（28.3.0.30732），人形优先。各层验证和历史基线见[验证摘要](VALIDATION.md)；未验证的组合不由已通过项目推导支持。

## 宿主与骨架

| 组合或对象 | 状态与范围 |
| --- | --- |
| Max 2026.3，Bone → Bone | FK、根运动、参考姿态、预览/烘焙/恢复及异数链通过隔离宿主验证 |
| Max 2026.3，Bone → Biped | 专用目标 API、新结果层事务及异数链通过隔离宿主验证 |
| Max 2026.3，Biped → Bone | 专用源读取、普通目标事务及异数链通过隔离宿主验证 |
| Max 2026.3，Biped → Biped | 专用读取/写入、新结果层事务及异数链通过隔离宿主验证 |
| 临时生成的普通 Bone 蒙皮人物 | 26→23 节点，可见操作、数据、保存重开及 12 页截图教程验收通过 |
| Biped 可见角色与用户生产角色 | 尚未完成相应角色人工效果验收 |
| Max 2026 其他补丁、其他年份 | 未验证 |
| CAT、约束、脚本/表达式、复杂自定义控制器 | 不作为可写目标支持 |

普通目标仅接受已识别的 PRS 及位置/旋转/缩放子控制器；冻结、锁定、约束、未知控制器和动画缩放会被拒绝。Biped 目标限可写的自由形态动画状态，Figure、Footstep、Motion、Mixer、Move All、Buffer 以及冻结状态会被拒绝；工具不自动切换这些状态。

源与目标必须是独立骨架，不能互为祖先，也不能把同一个 Biped 的不同肢体作为两侧。

## 动画能力

| 项目 | 策略与限制 |
| --- | --- |
| FK 与参考姿态 | 使用源参考世界旋转变化和目标参考姿态，按目标父空间恢复局部旋转 |
| 骨长 | 默认保持目标局部位置与骨长；显式启用逐链平移权重时可改变骨长 |
| root 与 hips | 独立单对映射；根策略为全局、原地、水平位移与朝向 |
| 尺度 | 自动、手动或关闭；影响根运动和显式平移，不复制所有子骨平移 |
| 不同参考骨轴与多级父空间 | 已有数学和宿主检查；反射与非正交变换受预检限制 |
| 非均匀、负或动态缩放 | 拒绝，不提供此类缩放求解 |
| 不同链节点数 | 脊柱/颈/头自动按参考世界弧长重采样；其他连续链须显式选择 |
| 空间扭转 | 相邻源节点旋转变化采用最短弧，不支持跨 180°或多圈极端空间扭转 |
| 时间跨 180° | 四元数符号连续；普通目标真实 Euler 动画及中点另有检查 |
| IK、pole vector、末端位置锁定 | 未实现 |
| 脚接触、足底稳定 | 未实现 |
| 任意扭转骨自动分配、更多 Biped 结构与大场景性能 | 未完成对应验收 |

重采样要求两侧完整连续父子链、各至少两个不同位置节点、无零长段，第一与最后节点语义对应。根与骨盆不允许重采样；所有重采样链平移权重必须为 0。

完整旋转权重、零偏移时，重采样两端保留对应源端点的世界旋转变化，中间节点按参考世界弧长插值。该能力不保证末端世界位置重合。预设 schemaVersion 2 保存模式，旧 schemaVersion 1 读取为逐节点映射。

## Biped 原生身体平衡

Biped 目标必须选择新动画层输出，所有写入限本次事务专属的新结果层。成功烘焙后结果层保持当前且激活；取消、异常或显式恢复删除新层并恢复旧层状态。

Biped 在设置旋转时可能因原生身体平衡改变局部位置，继而影响膝部读回。工具基于最新实际局部位置和目标旋转，仅对实际出错的完整同侧原生三段人形腿进行有限足端校正，最多两次，之后继续严格核对旋转。

参与节点包括同侧原生大腿、小腿、脚、脚趾及参与该腿求解的其他非 nub 节点。缺参与者会拒绝并回滚；读回仍不合格也会回滚。工具不修改未映射节点、旧层或 IK 设置。无需校正的局部映射继续使用原写入路径。更多腿结构和复杂角色未验证，这项有限适配不提供 IK 重定向或足底锁定。

## 恢复与范围边界

显隐记录节点隐藏状态，区分层、类别和父级导致的最终不可见；不对整场景 Unhide All，不揭开共享隐藏层。Max 2026.3 隐藏层内部分节点隐藏写入会被宿主忽略，工具保留原标记并报告显示请求受阻。

普通 PRS 与 Biped 使用不同事务。完整采样后再写入，预览、取消和异常恢复不依赖盲目执行一次全局 Undo。「恢复上次烘焙」仅保存当前窗口内的一次成功烘焙前备份；关闭不会撤销成功烘焙，关闭后不承诺 Ctrl+Z 可回退。

范围前后各 1 帧添加原姿态保护键，保留其他原区间外 key。已有证据只覆盖相应采样点，边界附近插值仍可能变化，不能推导连续时间完全不变。

配置改动、节点失效、控制器或层级变化需重新预检。JSON 预设提供可迁移身份提示，重名歧义须确认；重绑后重新检查参考姿态。

## 验证与安装的区别

四向基础宿主、异数链、实际 Skin 后台、离屏 UI、临时人物屏幕和 PDF 分别验证。生产角色验收仍待完成，临时 Bone 屏幕案例不代表 Biped 屏幕验收。公开 Release 下载和 LXTools 安装结果应以该版本的发行记录为准，包格式校验不能替代安装或动画效果验收。
