# Max 工具集 · 骨架重定向

本目录为 Max 工具集的重定向子工具，与绑定蒙皮、LX 飘带并列。中文操作窗口位于 Max 内；工具架负责选择明确的 Max 实例和打开入口。后续开发、版本和发行随父仓库 [3dmaxScript](https://github.com/gd-dd/3dmaxScript)，不再单独发行新版或提供独立商店 marker。

独立 LXMaxRetarget 的 `0.0.1` 仓库、标签、Release 和既有用户安装保留历史。父包发行及真实安装入口验证通过前，不退役该独立标识；历史发行和安装不会因此被删除。

## 安装和打开

1. 通过 LXTools 安装或更新「Max 工具集」，或从[父仓库公开 Release](https://github.com/gd-dd/3dmaxScript/releases)下载 `LXTool-package.zip` 并完整解压。只有包含本子目录的父包才提供重定向入口。
2. 在工具集面板中明确选择已连接的目标 Max 实例，再打开「骨架重定向」；目标退出后不得自动切换到其他实例。
3. 不使用工具架时，在需要工作的 Max 中用「脚本 → 运行脚本」执行父包根目录的 [LX_Retarget.ms](../LX_Retarget.ms)。保留完整父包，不能只复制入口或本子目录。
4. 工具在执行入口的实例内工作，源与目标骨架须处于同一个场景。首次使用先保存场景副本。

当前支持范围为 Max 2026.3 的普通 Bone 与 Biped 人形 FK、根运动和完整语义链重采样。依赖 Max 自带的 Python、pymxs 和 PySide，不需要 numpy/scipy 等额外数学库。

## 启动契约

父根 `LX_Retarget.ms` → `bridge/open_retarget.py` → `retarget.launcher.show(session=None)`。

公共入口、实例路由和资源清单由 Max 工具集维护；本目录负责业务窗口、核心、宿主与会话。默认参数创建明确宿主中的 Session，返回 Max 内窗口；导入核心本身不应打开窗口或改变场景。已加载版本、旧窗口和忙碌/恢复失败的切换处理由启动路由协调，避免旧独立版与父包同时持有同一场景的恢复状态。

本子工具使用平铺的 `retarget.*` Python 包，保留内部相对导入。不要改回独立版的 `scripts/start.py` 启动链，也不要同时挂载 `lxmaxretarget.*` 别名来绕过版本归属检查。

## 使用流程

1. 分别读取源、目标骨架，确认两侧对象归属，再分别记录参考姿态。
2. 在同一张关键链表中编辑对应关系；自动匹配提供候选和原因，确认后才应用。
3. 根与骨盆独立单对配置。脊柱、颈、头可按完整连续链进行不同节点数的弧长重采样；其他连续链须明确选择模式。
4. 配置根运动、尺度、范围与输出；普通 Bone 可拒绝已有动画或覆盖区间，Biped 必须选择新结果层。
5. 预检后预览、恢复，再确认烘焙。预设换场景或改名后检查重绑定及参考姿态。
6. 检查源动画、实际变形、范围边界与未映射轨道，再保存结果。

默认保留目标局部骨长；所有重采样链平移权重必须为 0，末端旋转运动保持不代表末端位置锁定。Biped 原生身体平衡有限校正仅限完整映射的同侧原生三段人形腿及脚趾等参与节点，只写本次新结果层，缺节点或读回不合格会拒绝并回滚。

IK、pole vector、末端位置锁定、脚接触和足底稳定未实现；CAT、约束和复杂控制器不作为可写目标支持。其他 Max 版本、更多 Biped 结构和生产角色仍待验证。

独立 `0.0.1` 基线已有 Bone/Biped 四向与异数后台验证；临时生成的 Bone 蒙皮人物完成屏幕操作、数据核验、保存重开和 12 页截图教程验收。生产角色和 Biped 屏幕案例仍待验收。这些是业务基线，不能代替本次父包迁移、发行、客户端安装和指定 Max 入口验证。

[兼容矩阵](docs/COMPATIBILITY.md)、[验证摘要](docs/VALIDATION.md)及 [API 契约](API_CONTRACT.md)保留原基线文本。文中的 `0.0.1` 指独立业务基线，不是父包版本；其中独立发行流程描述不再作为当前集成入口。

「恢复上次烘焙」只保留当前窗口会话内的一次成功烘焙前备份；关闭不撤销成功结果，关闭后不承诺 Ctrl+Z 可恢复。范围前后各 1 帧保护键不保证邻接区间所有插值完全不变。
