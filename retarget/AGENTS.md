# 重定向子工具开发入口

本目录是 Max 工具集内的 L3 重定向业务子目录，采用平铺 `retarget.*` 包。先读适用的父级 `AGENTS.md`，再读本目录 [README.md](README.md)、[TODO.md](TODO.md)、[API_CONTRACT.md](API_CONTRACT.md)、[兼容矩阵](docs/COMPATIBILITY.md)与[验证摘要](docs/VALIDATION.md)。

## 文件归属

- 重定向组件负责人维护本子目录：数学/模型/求解、预设/匹配、Max 宿主/会话、业务 UI、launcher 和本地文档。并行工作时先确认各文件写入者。
- Max 工具集负责人 maxsuite 独占父公共文件：根入口 `LX_Retarget.ms`、`bridge/`、`ui/`、工具清单、`.lxtool/manifest.json`、父级说明/TODO、构建与打包。
- 涉及公共入口、namespace、实例路由、资源清单或其他子工具的变更先协调，不越界修改公共文件，不复制其他工具私有桥接。

## 集成约束

入口为父根 `LX_Retarget.ms` → `bridge/open_retarget.py` → `retarget.launcher.show(session=None)`。只向明确实例运行，目标退出不自动切换。业务会话和恢复事务留在本目录。

基线迁移以独立 LXMaxRetarget `0.0.1` 已验收文件为依据。未改算法的文件保留字节及换行并核对 SHA-256；入口适配单独记录，不将原测试结论冒充父包集成重测。

不复制独立 `.lxtool`，不再创建独立新版。原独立仓库、`0.0.1` 标签/Release 和用户安装保留；父包发行与真实安装入口验证通过前，不退役独立默认商店标识。

## 安全与证据

宿主访问留在 Max 主线程。遵循最新用户指令及父级约定；本组件未经单独授权不控制屏幕、不操作用户当前 Max 场景。验证使用纯数据、离屏 UI 或隔离后台专用场景。

历史基线、迁移字节一致性、自动测试、父包资源与路由、后台宿主、可见窗口、实际安装及正式发行分别记录。IK/接触/CAT 和生产角色的未验收边界不得被已有 FK 结果覆盖。

临时人物场景、PDF、原始截图、私有 profiles、缓存和失败探针不进入业务包。输出位置和本机磁盘限制遵循适用的父级约定，不写独立历史目录。提交、push 和发行由对应负责人按当前明确授权执行。
