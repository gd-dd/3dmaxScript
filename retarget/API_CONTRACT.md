# Core API contract (2026-11-09)

All modules are dependency-free Python. Transform convention is right-handed Hamilton quaternion `(x,y,z,w)` with active column-vector rotations. Host converts Max row-matrix/quaternion conventions. Transforms passed to the solver are LOCAL to included parent; a node whose parent is absent uses WORLD space. No transform changes occur in core.

- `math3d.Transform(position=(0,0,0), rotation=(0,0,0,1), scale=(1,1,1))` frozen dataclass. `compose(parent, local)`, `relative(parent, world)`, `q_mul`, `q_inv`, `q_rotate`, `q_slerp`, `q_axis_angle`, `q_angle`, `world_transforms(nodes, locals)` (in model) available.
- `model.Node(id: str, name: str, parent: str|None=None, path: str='', kind: str='bone', writable: bool=True, constraints: bool=False, animated: bool=False)` frozen dataclass. source/target each `dict[str,Node]`.
- `model.Chain(name: str, source: list[str], target: list[str], kind: str='custom', rotation_weight: float=1.0, translation_weight: float=0.0, offset: tuple4=(0,0,0,1), enabled: bool=True, mapping_mode: str='auto')` dataclass. `root` chain kind transfers translation; ordinary chains preserve target local translations unless explicit translation_weight > 0.
- `model.Settings(start: int=0,end: int=30,step: int=1,root_mode: str='global',scale_mode: str='auto',scale: float=1.0,reference_frame: int=0,existing_animation: str='reject_existing')`. root_mode `global|in_place|horizontal`, scale_mode `auto|manual|none`. `frames()` yields inclusive start/end (always end).
- `model.SessionConfig(source:dict[str,Node],target:dict[str,Node],chains:list[Chain],source_reference:dict[str,Transform],target_reference:dict[str,Transform],settings:Settings=Settings())` dataclass.
- `model.preflight(config)->list[Issue]`, Issue(severity='error|warning',code,message,node_id=''). `model.humanoid_chains()->list[Chain]` blank preset rows. Unequal counts require an eligible automatic semantic span or explicit resampling; see the precise policy below. CAT/constraints/nonuniform/negative scales unsupported write errors. Biped acceptance depends on host writable capability.
- `solver.solve(config, samples:dict[frame,dict[node_id,Transform]], cancelled=None, target_samples=None)->dict[frame,dict[target_id,Transform]]`. Complete samples of included source skeleton required. `target_samples[frame]` full actual target locals are required if any unmapped target node has animation; provide always to account for actual target parent rotations and retained target translation. Output LOCAL target transforms ONLY mapped nodes. Pure calculation, no host mutation. Raises `ValueError` on invalid config, `CancelledError` on cancellation. `solver.effective_scale(config)->float`.
- `matching.suggest(source_nodes,target_nodes)->list[Suggestion]` containing source_id,target_id,confidence,reason. Suggestions never mutate chains. `matching.mirror_name(name)->str`.
- `preset.dumps(config)->str`, `preset.loads(text)->SessionConfig`, `preset.save(path,config)`, `preset.load(path)` strict JSON schemaVersion 2; schema 1 loads with direct mapping to preserve its original semantics. File IO is atomic. Persisted IDs are portable preset identifiers plus path/name/parent hints, never treated as live handles.
- `preset.rebind(config,source_nodes,target_nodes)->(SessionConfig,list[BindingIssue])`. Automatic binding only unique exact full path; unique name/renamed/namespace candidates remain BindingIssue(side,preset_id,name,candidates,reason) requiring explicit user choice. `preset.apply_bindings(config,source_nodes,target_nodes,source_bindings,target_bindings)->SessionConfig` accepts explicit dictionaries old IDs to current IDs; unresolved nodes remain in model with `writable=False`, mapping to them fails preflight. References are remapped with bindings.

Root strategy applies to chain.kind='root' (one root node pair). Pelvis is separate. Default auto scale = median of corresponding non-zero direct parent-child world-length ratios and resampled overall semantic span ratios; no valid contribution => 1. Rotation uses source world delta relative to reference and target reference world rotation, solved target-parent-first; target local bone length preserved. Quaternion output signs aligned frame-to-frame. No IK/contact/CAT solver support is claimed. Biped uses skeleton-neutral math and requires host-specific writes and validation.

## Semantic chain resampling contract

`Chain.mapping_mode` is a final optional dataclass field, default `auto`, preserving existing positional construction. `model.chain_mapping_mode(chain)` resolves it to `direct` or `resample`. `auto` keeps equal-count direct behavior; unequal counts resample only for `spine`, `neck`, or `head`. Explicit `resample` permits any continuous chain except `root` and `hips`, which require exactly one source and one target joint and reject explicit resampling. `direct` requires equal counts. Source joints may be read by multiple chains; each target joint has exactly one enabled chain owner.

The first and last LISTED joints are semantic start/end anchors, not their parents. `math3d.polyline_parameters(points)` returns `(normalized_parameters, world_arc_length)` from consecutive REFERENCE WORLD positions. Each side needs at least two listed joints and every consecutive edge must have positive length (edges <= 1e-7 scene units are rejected; no silent merging). For target coordinate `t`, source world motion deltas `D_i = sourceWorldCurrent_i * inverse(sourceWorldReference_i)` are interpolated with shortest-path quaternion slerp between adjacent SOURCE arc coordinates. Desired target world rotation is `D(t) * targetWorldReferenceRotation`. Parent-first target solving converts that world rotation to local space, then applies the existing local rotation weight and offset. At weight 1 / identity offset, start and end rotation deltas are exact source endpoint deltas. Local target translations and scales remain unchanged. ALL resampling with nonzero translation weight is rejected, including equal-count explicit resampling; root/hips displacement stays separate. Direct chain local translation is reference position + source local delta * scale * weight, so re-baking does not accumulate target translation. Temporal quaternion signs remain continuous.

Automatic scale excludes resampled joints from zip-based edge comparisons and contributes ONE ratio per resampled semantic span: target reference total world arc length / source reference total world arc length. Direct chains retain corresponding actual parent-child world-length ratios. The effective scale remains the median of all eligible edge/span contributions. No IK/contact behavior is implied by this rotation resampling.
