# Max 工具集

在 LX 工具架同一个面板中打开多个 3ds Max、选择目标窗口，使用绑定蒙皮工作台或原有六款脚本。图标沿用用户提供的图片。

## 绑定蒙皮工作台

模型和视口留在 Max，新增功能全部放在工具架的「绑定蒙皮工作台」页签内。

1. 选择已连接的 Max，点击「读取 / 刷新场景」，选择模型与 Skin。
2. 在「骨骼与绑定」查看任意分支层级，按住 Ctrl 多选影响节点，建立 Skin；可创建骨骼、重命名、修改父对象、增减影响节点、记录和恢复当前姿态。
3. 点击「读取当前模型权重 / 角色配置」。在「权重」设置定值或增量，归一化、平滑、清理小权重、限制影响数、锁定影响节点。默认只修改 Max 中已选的 Skin 顶点；整模型操作要选择「全部顶点」。
4. 在「镜像与交换」保存左右影响配对，然后设置轴、方向和容差。镜像按模型当前局部坐标匹配；传递按当前世界空间最近顶点匹配，作用于整个目标模型。姿态应对齐，薄面和关节需要人工检查。
5. 在「人形与表情」给节点指定人形或面部语义角色，角色名称可自定义，手指、扭转骨、尾巴和额外骨链不受模板数量限制。角色映射不自动创建 IK/FK 控制器。Morpher 可从同拓扑目标建立通道、调整值和归零；新建 Morpher 自动放在 Skin 之前计算，请在合适的基础姿态制作表情目标。
6. 在「检查与恢复」查看非法权重、缺失影响和影响数超限，并在 Max 选择问题顶点；也可保存与恢复权重快照。

修改命令支持 Max 撤销，失败时回滚；权重修改前自动保存 JSON 快照，写入后重新求值并读回核对。快照目录为 `%LOCALAPPDATA%/LXMaxTools/rig-snapshots`，只在同一场景会话中恢复；跨重开请保存 Max 场景，或导出权重 JSON。导入要求三角拓扑签名相同，骨骼按同场景节点标识或唯一名称映射，不猜测重名骨骼。

影响锁定用于权重页的数值编辑、归一化、平滑和清理。镜像、传递、导入及快照恢复属于权重替换操作，不使用该编辑锁定。

解除 Skin 前会创建快照。唯一 Skin 的快照还记录绑定与拉伸矩阵，可重建权重绑定；其他修改器参数、DQ、包络、动画等不属于权重快照，完整恢复仍用 Max 撤销或场景文件。多个 Skin 时选择明确的修改器，不支持靠权重快照重建已删除的多 Skin 堆栈。

普通 Bones、自定义层级及 Helper 影响节点使用通用流程。Biped/CAT 可作为 Skin 影响节点，但其内部层级由各自系统管理，工具不把它们当普通 Bones 强制重设父子关系。本版不包含自动 IK/FK、人形控制器生成、自动面部 rig、分层权重求解器或视口画笔。

## 使用流程

1. 在「打开 Max」选择 3dsmax.exe，点击「+ 打开 Max」。每次点击打开一个独立实例。
2. 等待「选择已连接窗口」显示已连接；如 Max 自身出现启动提示，请先完成提示。新开的 Max 会自动加载连接桥。点击「连接 / 刷新」可恢复本工具已经打开的窗口列表。
3. 选中目标窗口，再点击下方工具卡片。执行结果显示在面板底部；换一个窗口即可在其他 Max 打开同一款工具。

所有管理操作都在当前工具架面板内，不会打开独立控制台。插件自身的原有窗口仍在目标 Max 中显示。仅跟踪本工具启动的实例，不扫描或接管用户自行打开的 Max，也不安装全局启动脚本。

## 包含工具

- 动画烘焙：按采样间隔烘焙动画。
- 公式关键帧：用公式调整关键帧。
- 父子层级：建立层级并保留世界动画。
- 根骨骼约束：将根骨骼运动烘焙到虚拟体。
- 材质 ID 拆分：按材质整理模型部件。
- PMX 导入：导入模型与相关资源。

## 连接与兼容性

需要 Windows x64、.NET Framework 4.x，以及支持 native API 1 的 LX 工具架（最低 0.5.0）。连接桥已在本机 3ds Max 2026.3 验证；其他 Max 版本尚未验证。

关闭工具面板或退出工具架不会关闭 Max。重新进入同一工具版本后点击「连接 / 刷新」可恢复连接。实例通过 PID 和启动时间共同识别，避免把命令发到 PID 被复用的其他进程。Max 忙于计算或模态对话框时会显示暂未响应；请等待任务结束。

连接与已打开实例按工具安装目录隔离。切换或升级工具版本后，请用该版本重新打开 Max；旧版本实例仍可回到旧版本面板管理。运行中的工具版本请不要卸载。

后台只接受六款脚本的固定标识及工作台注册命令，不接受任意脚本路径。工作台命令带目标实例与场景令牌，切换场景后必须重新读取。脚本请求期限为 30 秒，工作台为 5 分钟；「取消」仅取消 Max 尚未接收的请求，不中断已经开始的场景修改。大模型计算期间 Max 可能暂时忙碌。关闭面板不会关闭 Max，也不会中断已开始的命令。

工作台已在 Max 2026.3 的测试几何中验证；其他 Max 版本、生产角色的大规模性能、Biped/CAT 专用控制器行为尚未完成验收。宿主需要 pymxs 和 PySide6。
