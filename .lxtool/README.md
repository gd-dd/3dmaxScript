# Max 工具集

所有工具界面都在 3ds Max 内使用。LX 工具架仅负责启动 Max、选择目标实例并打开工具。十项工具统一使用用户提供的图片和绿色视觉层级。

## 绑定蒙皮工作台

工作台首次打开为可缩放悬浮窗口，可手动停靠。重复打开会聚焦已有面板并保留停靠状态；关闭重开不删除模型或骨骼。模型与骨骼 / 控制器分栏独立多选，场景工作集、当前模型和 Skin 可在各步骤复用。

**从 LXTool 打开：** 在工具架选择已连接窗口，点击「绑定蒙皮」，随后在该 Max 内操作。

1. **导入与整理**：点击「读取 / 刷新场景」，读取已有模型、Bone、Biped 和辅助控制器；也可把视口选择加入工作集。分类显隐、包围框及视口线框 / 边面 / 选择外框在后续步骤持续可用。
2. **自由人体骨架**：拖出人物高度，或输入高度生成普通 Bone 骨架。拖动时显示骨架预览；脊柱、颈部、肢体链节数及手指脚趾可配置。生成时不加 IK、不锁长度，包含独立肩 / 锁骨、质心与骨盆，可继续移动、旋转调整。
3. **自定义与定位**：为选中父骨添加、连续顺延子骨骼，从对象轴心或所选顶点中心取点，创建平均中心 Point，或对齐骨骼端点。提供左→右、右→左及编辑后自动同步的骨架对称，使用世界 X 中线。
4. **IK 与长度定型**：为工具生成人体的手臂、腿添加 HI IK 并固定长度。默认中间分段不参与弯曲，可按需启用；脊柱、颈部和手指保持 FK。任意外部骨架不会被自动猜测为人形 IK。
5. **控制器**：创建圆环、方框或 Point 控制器和世界中心 Root，按所属骨架尺寸适配显示；为普通对象插入父级控制器时保留世界变换和原有动画控制器。
6. **自动蒙皮**：多选模型，以 Max 包络、骨骼线段距离或体素内部距离场生成初始 Skin 权重。分步模式逐模型推荐影响骨骼，允许调整骨骼栏多选后确认；自动批量模式使用同一推荐逻辑。体素模式要求封闭流形网格，是本工具的 CPU 距离传播实现，不等同于 Maya 求解器。
7. **权重与笔刷**：持续查看所选骨骼合计的权重颜色，按骨骼 / 顶点赋值、加减、归一化、平滑及逐点保留 N 个影响；支持点线面与混合选择、循环 / 环选、隐藏 / 仅显示。视口笔刷提供加、减、赋值、平滑，Shift 临时平滑、Ctrl 临时减值、右键退出。数值框禁止滚轮改值。

「辅助」保留逐骨骼 / 锁定、镜像与交换、人形与表情、检查与恢复。权重镜像按模型局部坐标匹配，传递按当前世界空间最近顶点匹配，需检查薄面和关节；角色映射可自定义，但不自动生成完整面部 rig。Morpher 支持同拓扑目标通道、调整值和归零，新建 Morpher 放在 Skin 之前计算。

修改命令支持 Max 撤销，失败时回滚；权重修改前自动保存 JSON 快照，写入后重新求值并读回核对。快照目录为 `%LOCALAPPDATA%/LXMaxTools/rig-snapshots`，只在同一场景会话中恢复；跨重开请保存 Max 场景，或导出权重 JSON。导入要求三角拓扑签名相同，骨骼按同场景节点标识或唯一名称映射，不猜测重名骨骼。

影响锁定用于权重页的数值编辑、归一化、平滑和清理。镜像、传递、导入及快照恢复属于权重替换操作，不使用该编辑锁定。

解除 Skin 前会创建快照。唯一 Skin 的快照还记录绑定与拉伸矩阵，可重建权重绑定；其他修改器参数、DQ、包络、动画等不属于权重快照，完整恢复仍用 Max 撤销或场景文件。多个 Skin 时选择明确的修改器，不支持靠权重快照重建已删除的多 Skin 堆栈。

普通 Bone、自定义层级及 Helper 影响节点使用通用 Skin 流程。已有 Biped 可读取、分类显隐并用于 Skin；其层级与 IK 继续由原生系统管理，普通 Bone 定型和控制器插入不会改写 Biped。CAT 影响节点与专用控制器的完整工作流未验收。Physique 模型可以列出，但不编辑 Physique 权重。本版没有完整自动 IK/FK 切换系统、自动面部 rig 或分层权重求解器。生产角色的绑定效果、复杂拓扑选择和笔刷手感仍需检查。

## 使用流程

1. 点击「打开新 Max」。首次选择 3dsmax.exe，以后可在「连接设置」中更改程序。每次点击打开一个独立实例。
2. 已打开的 Max 会自动发现，只有一个可用窗口时自动选中。多个窗口时用下拉框选择。如 Max 出现启动提示，请先完成提示；新开的 Max 会自动加载连接桥。窗口标题省略时可悬停查看完整名称，完整窗口列表在连接设置内。滚动面板不会改变目标。
3. 在「角色与绑定」「动画处理」「模型与导入」中选择工具。入口按面板宽度排列；小窗口可纵向滚动查看全部十项。换一个目标窗口即可在其他 Max 打开同一款工具。

工具架只保留实例管理和打开入口；所有绑定、蒙皮和脚本操作都在目标 Max 内的窗口中完成。列出所有已打开的 Max；连接就绪后，工具仅向目标实例发送操作。

## 其他工具的统一界面

六款既有脚本保留 Max 内原生窗口，统一为顶部头像与用途说明、编号分区、清晰的主次按钮。公式参考与示例在原窗口内展开，主动作保持常见；保留原有选择、选项、帧范围及业务逻辑。脚本需要与 `ui/legacy_theme.ms` 和 `.lxtool/icon.png` 一起保留。

## 包含工具

- 动画烘焙：按采样间隔烘焙动画。
- 公式关键帧：用公式调整关键帧。
- 父子层级：建立层级并保留世界动画。
- 根骨骼约束：将根骨骼运动烘焙到虚拟体。
- 材质 ID 拆分：按材质整理模型部件。
- PMX 导入：导入模型与相关资源。

## 连接与兼容性

需要 Windows x64、.NET Framework 4.x，以及支持 native API 1 的 LX 工具架。连接桥识别 3ds Max 2023–2027，并按进程实际程序版本连接；本机宿主验证为 2026，其他版本完成版本识别/协议测试，未冒称各版本实机通过。2023/2024 使用 PySide2，绑定蒙皮/飘带/重定向/UV 重叠的 PySide6 窗口需要 2025及以上；连接桥和六个 MAXScript 入口不依赖 PySide6。

关闭工具面板或退出工具架不会关闭 Max。重新打开工具时自动恢复可用连接。实例通过 PID 和启动时间共同识别，避免把命令发到 PID 被复用的其他进程。Max 忙于计算或模态对话框时会显示暂未响应；请等待任务结束。

打开工具面板会准备自动连接组件。Max 启动时自动加载组件，跨工具接入或连接组件更新会在 Max 空闲后完成。安装前已打开的 Max 会在界面空闲后自动接入。若其正在使用脚本输入区，暂缓接入。已加载不同安装目录的绑定蒙皮、飘带和重定向业务界面时，切换这些业务模块版本仍需重开 Max。

启动后台只接受工具固定标识，不接受任意脚本路径。工作台在所在 Max 内直接调度注册命令，不通过工具架传递权重操作；场景令牌变化后自动清空编辑目标，必须重新读取。脚本请求期限为 30 秒，工作台为 5 分钟；「取消」仅取消 Max 尚未接收的请求，不中断已经开始的场景修改。大模型计算期间 Max 可能暂时忙碌。Max 面板关闭时取消本地尚未开始的命令，不关闭 Max。旧远程注册命令通道保留兼容用途，不作为当前工作台 UI 的操作路径。

工作台已在 Max 2026.3 的测试几何中验证；其他 Max 版本、生产角色的大规模性能及 CAT 专用控制器工作流尚未完成验收。宿主需要 pymxs 和 PySide6。


## 选择已打开的 Max

连接列表支持手动打开及工具启动的 Max，按窗口标题和 PID 区分。选择目标后，操作只发送给该窗口；窗口退出不会转发给其他实例。

窗口下拉关闭时分两行显示场景与版本/PID/状态；展开后用三行条目显示完整身份与路径，弹出范围按当前屏幕限宽并支持滚动。省略显示不改变真实实例标识，完整内容可在提示中读取；关闭下拉、滚轮、刷新和目标退出都不会静默切到另一个 Max。

## 操作与恢复边界

同场多套骨架分别计算显示尺寸并使用各自 Root；已有外部父级不会被整体挂到新 Root。子骨骼取点只记录当前坐标，方向点只定方向，实际长度由独立长度框决定。完整说明见包内 `docs/rig-workflow.md`。

权重页默认作用于所选 Skin 顶点；整模型修改请明确选择「全部顶点」。「仅当前选中骨骼影响」则作用于所选模型的全部顶点，移除未选骨骼权重并归一化；原来没有保留影响的点交给最近的保留骨骼。存在未选且锁定的非零影响时会拒绝操作。

视口选择层 `LX_Selection` 仅用于选区和显隐，不要在该层增删或重排顶点。循环 / 环形依赖规则拓扑及正确种子；复杂极点不能保证完整延续。权重颜色覆盖不修改模型材质或渲染设置。

「检查与恢复」可保存完整 Max 场景副本，与仅记录权重和绑定矩阵的快照不同。完整恢复优先使用 Max 撤销或场景文件。窗口可调整左右 / 上下分区，低频设置在步骤内展开；白底、深绿选中项与用户提供的图片保持一致。

同一安装目录更新后，再次呼出会检查摘要并重载实现；开始重载前需结束笔刷笔划。不同安装路径的 Python 业务版本切换仍需重启 Max，请先保存场景。

## LX 飘带（工具集子工具）
在目标 Max 中点击「LX 飘带」，或运行完整包根目录 LX_Ribbon.ms。选择普通 Bone 单链根骨骼，读取后设置重力、惯性、质量、长度影响系数、阻尼和帧范围，再解算烘焙。末节作为末端定位；烘焙可用 Max 撤销。不支持分叉、CAT/Biped、碰撞和运行中取消；失败后重新读取骨链。迁自 LXRibbon v0.0.1，历史独立仓库与发行仅作追溯。

## 骨架重定向（工具集子工具）

在目标 Max 中点击「骨架重定向」，或运行完整包根目录 `LX_Retarget.ms`。源、目标在同一场景，分别读取骨架和参考姿态，确认关键链对应表，预检、预览后烘焙。支持普通 Bone / Biped 的人形 FK、根运动及语义链重采样；Biped 输出到新结果层。IK、pole vector、末端位置锁定和足底稳定未实现，CAT / 复杂约束目标不在可写支持范围。详见包内 `retarget/README.md`。

## 六款脚本的验证范围
六款工具已用独立 Max 2026 合成场景验证核心结果、撤销与主要无效输入。PMX 验证覆盖三角网格、UV、材质、普通骨骼层级及 BDEF1/2/4 权重；SDEF 按 BDEF2 近似，物理、非顶点变形等不重建。这些检查不代表所有商业 PMX 模型、第三方控制器或用户交互手感均已验收。公式三角函数采用 MAXScript 原生角度制，应用可以撤销。

## UV 重叠

在同一物件的 Unwrap UVW 编辑器里，给两个 UV 块各选一整圈外边界，然后打开「UV 重叠」。可使用边模式，也可在点模式选完整圈。绿色 A 固定，橙色 B 对齐到 A。孔洞自动配对，原始 UV 预览标有孔编号，可在配对面板手动指定对应的 B 孔或选择不配对。相位、镜像与孔配对实时预览。点「应用到 UV 编辑器」写入，可通过 Max 撤销。需要 Max 2025–2027。
