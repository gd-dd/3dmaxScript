# Max 工具集

**一个仓库，一个工具。** 这是 gd-dd 的 3ds Max 实用脚本集合。

## 包含功能

| 功能 | 用途 |
| --- | --- |
| 动画烘焙 | 对位移、旋转和缩放按采样间隔烘焙 |
| 公式关键帧 | 通过公式调整关键帧 |
| 材质拆分 | 按材质 ID 拆分模型 |
| 父子层级 | 建立父子关系并保持世界动画 |
| PMX 导入 | 导入 PMX 模型 |
| 根骨骼清理 | 转移根骨骼运动 |

## 如何使用

1. 安装此工具，进入「工具面板」。
2. 在面板中选择本机的 `3dsmax.exe`，填写实际软件版本。
3. 点击需要的功能；会启动**新的 Max 实例**并执行相应脚本。
4. 如需复制脚本到用户 scripts 目录，使用「安装脚本到所选目录」。
