# 工具集布局与使用顺序

工具架面板按三个步骤排列：打开新 Max、用下拉框连接并选择窗口、在选中 Max 中打开工具。只有用户明确点击启动或连接时才运行连接后台；单纯打开面板不会启动 Max。

九个入口分为角色与绑定、动画处理、模型与导入。面板按宽度排列为一至四列，小窗口可以纵向滚动。长场景名在目标摘要中省略，完整内容保留在提示中；实例标识和命令目标不随显示省略而改变。目标窗口退出后，工具不会自动转发到其他实例。

完整窗口详情、程序路径、首次连接脚本和自动连接放在“连接设置与首次连接”中。展开后在当前面板操作，复制脚本和安装结果也显示在这里。首次程序选择仍使用系统文件选择器。

六款原脚本继续在 Max 内运行，保留原有业务回调和撤销。简单工具以对象、参数、执行为阅读顺序；公式的完整参考可在原窗口内展开。头像使用用户提供的原图片。绑定蒙皮、飘带和重定向由各自模块维护 Max 内业务窗口，仍随同一父包安装。

本批验证区分离屏 Qt、隐藏 Max 原生控件、精确父包、公开下载和用户当前窗口。验收证据在生态根的 `acceptance/maxsuite-ui-2026-11-12` 与各子模块验收目录；只有实际执行过的范围才能标为通过。
