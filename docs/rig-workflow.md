# Max 分阶段绑定工作流

本次新增流程在 3ds Max 内使用，LXTool 仅打开入口。用户指定图片保留；界面采用 LX 白、嫩叶绿和轻香槟焦点色。

1. **导入与整理**：选择场景对象，自动分类或明确指定模型、骨骼、控制器；不会复制对象。顶部按钮按类别显隐。
2. **自由人体骨架**：视口定义底部与高度，或输入高度创建。Z 向上、面向 -Y。生成带角色标识和父子层级的普通 Bone，脊柱、颈部、上臂、前臂、大腿、小腿链节数可调；每侧 0–5 手指和脚趾，节数可调。生成阶段不加 IK、不冻结长度。
3. **自定义与定位**：选父骨骼创建子骨骼。点、边、面选择取唯一顶点的算术平均中心创建 Point 辅助体；骨骼起点/终点可对齐指定对象位置。先完成定位再定型。
4. **IK 定型**：为生成的左右手臂/腿添加 HI IK，固定 Bone 长度。脊柱、颈部和手指使用 FK。重复定型被阻止；回到修改阶段可撤销操作。自定义任意骨架保留原层级，不猜测其人形 IK 语义。
5. **控制器**：圆环、方框、Point 三类；创建世界原点 Root。IK 目标跟随控制器；为普通选中对象插入父级控制器，保留世界变换，不覆盖已有动画控制器。
6. **蒙皮**：Max 包络、骨骼线段距离、体素内部距离场。计算初始权重与实际 Skin 变形解算是两件事：结果写入标准 Skin，仍可使用其变形模式。
7. **权重**：逐骨骼编辑、多选骨骼合计赋值/加减、归一化、选点平滑、逐点保留最大的 N 个影响。多选骨骼内部保留原比例，原合计为零时均分；锁定影响保持不变。减值/赋值后若没有其他已有权重，剩余值均分到未选且未锁定的影响骨骼；若不存在可接收的骨骼则保持归一化。点线面选择可循环、环选、扩大、收缩，转换为 Skin 顶点；隐藏、仅显示和显示全部。视口笔刷支持加/减/赋值/平滑，Shift 临时平滑、Ctrl 临时减值、右键结束。

表情、人形映射、镜像、传递、导入导出与权重快照保留在辅助页。

## 计算与兼容边界

- 体素模式是本项目的 CPU 内部距离传播实现，参考 Geodesic Voxel 思路，不是 Maya 内置求解器，也不承诺与其数值一致。最长轴 8–64 个体素；封闭流形网格、骨骼位于内部是前提。过薄部位、孔洞、自交、不包含骨骼的独立体积会要求提高分辨率或修复，不静默改用线段距离。计算在 Max 主线程进行，大模型需要等待。
- 线段距离计算实际起点、终点及中间位置，不仅使用骨骼枢轴；普通非 Bone 影响使用对象位置。
- Skin 上方自动创建 `LX_Selection` Edit Poly 选择层，仅用来选择/显隐，不应用改变拓扑的操作。已有堆栈顶点数不匹配时拒绝转换。不要手动在该层增删或重排顶点。
- 笔刷以世界空间半径和柔和衰减进行绘制。窄缝、贴近表面可结合“仅选中顶点”和隐藏范围控制绘制区域；笔刷手感、复杂生产角色仍需人工验收。
- 人形模板是可调整 Bone 骨架，不是 Biped/CAT 控制器替代品。通用 Skin 骨骼仍支持原有对象；Biped/CAT 内部层级不由此工具强制改写。
