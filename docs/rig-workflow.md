# Max 分阶段绑定工作流

本次新增流程在 3ds Max 内使用，LXTool 仅打开入口。首次呼出默认悬浮，可手动停靠；同一个已打开面板再次呼出时保留当前停靠状态。用户指定图片保留；界面采用 LX 白、嫩叶绿和轻香槟焦点色。

1. **导入与整理**：选择场景对象，自动分类或明确指定模型、骨骼、控制器；不会复制对象。顶部按钮按类别显隐，并可分别切换模型、骨骼、控制器的包围框。线框、边面、选择外框作用于当前 Nitrous 视口，不改材质或渲染设置。读取的对象保存在全流程共用工作集里，切换步骤不需要重读，当前模型与 Skin 目标保持。
2. **自由人体骨架**：视口定义底部与高度，拖动时显示完整骨架和当前高度，右键取消不生成对象；也可输入高度创建。Z 向上、面向 -Y。生成带角色标识和父子层级的普通 Bone，脊柱、颈部、上臂、前臂、大腿、小腿链节数可调；每侧 0–5 手指和脚趾，节数可调。生成阶段不加 IK、不冻结长度。比例和放松垂臂姿态参考真实 Biped，肩部包含独立 L/R Clavicle，肘向后预弯、膝向前预弯；按部位设置 Bone 显示粗细。BodyCenter 是整体质心 Point，Pelvis 是宽横向骨盆 Bone；骨盆与脊柱分别挂在质心下，骨盆旋转带动双腿而不牵动上身。建立层级后重算骨段并校验连续关节，确保上臂末端与前臂根部相接。前缀留空不生成开头下划线，有前缀时只添加一个分隔下划线。
3. **自定义与定位**：选父骨骼创建子骨骼。点、边、面选择取唯一顶点的算术平均中心创建 Point 辅助体；骨骼起点/终点可对齐指定对象位置。先完成定位再定型。
4. **IK 定型**：为生成的左右手臂/腿添加 HI IK，固定 Bone 长度。默认仅肩肘 / 髋膝关节参与弯曲，大小臂、大小腿的中间分段保持刚性；勾选分段弯曲才允许中间节参与 IK。脊柱、颈部和手指使用 FK。重复定型被阻止；回到修改阶段可撤销操作。自定义任意骨架保留原层级，不猜测其人形 IK 语义。
5. **控制器**：圆环、方框、Point 三类；创建世界原点 Root。IK 目标跟随控制器；为普通选中对象插入父级控制器，保留世界变换，不覆盖已有动画控制器。
6. **蒙皮**：Max 包络、骨骼线段距离、体素内部距离场。计算初始权重与实际 Skin 变形解算是两件事：结果写入标准 Skin，仍可使用其变形模式。
7. **权重**：逐骨骼编辑、多选骨骼合计赋值/加减、归一化、选点平滑、逐点保留最大的 N 个影响。多选骨骼内部保留原比例，原合计为零时均分；锁定影响保持不变。减值/赋值后若没有其他已有权重，剩余值均分到未选且未锁定的影响骨骼；若不存在可接收的骨骼则保持归一化。点线面选择可循环、环选、扩大、收缩，转换为 Skin 顶点；隐藏、仅显示和显示全部。视口笔刷支持加/减/赋值/平滑，Shift 临时平滑、Ctrl 临时减值、右键结束。

表情、人形映射、镜像、传递、导入导出与权重快照保留在辅助页。

## 共用工作集与窗口布局

首次打开是可缩放悬浮窗口。左侧对象框在所有步骤可用：只有一条上下分割线，上方模型，下方通过骨骼 / 控制器页签切换，Ctrl / Shift 多选互不覆盖，显示实际父子关系、原对象名及中文部位（如左肩、上臂、身体质心、骨盆 / 摆胯），支持搜索、展开折叠、同步选择到 Max。选中一个模型可直接设为当前模型。默认只显示已纳入工作流的对象及必要祖先，没有工作流对象时显示整个场景。读取或导入后，所有步骤复用这份场景数据。

拖动中间分隔线分配宽度，或选择上下分区。创建骨架、自定义定位、权重编辑在宽窗口中并排展示，窄窗口自动转为纵向排列；不强制长条停靠。对象树可滚动；窗口很矮时左侧目标控制区也可滚动。

“辅助 → 检查与恢复”可检查骨骼连接，并保存完整 Max 场景副本到 `%LOCALAPPDATA%/LXMaxTools/scene-backups`。这个副本包含完整场景，区别于原有仅含权重的快照，默认不改变当前场景文件名。

## 骨架对称

在“03 自定义与定位”选择左→右或右→左，先在 Max 视口选骨架中的一个骨骼，然后点“对称选中骨架”。默认处理该骨架整侧，关闭“整侧”可只处理选中骨骼及其子骨骼。配对以骨架身份和角色标识隔离，多个人物不会串联；自定义普通 Bone 可按 L_ / R_ 或 _L_ / _R_ 命名。

镜像平面为世界 X 中线：生成骨架默认读取身体质心 X，旧骨架回退为骨盆 X，其他骨架手动填写中线 X。同步位置、朝向、长度和显示粗细，保留右手坐标系及对侧层级，不改未选子树外对象。旋转过的人物应先对齐世界 X 中线；此版不提供任意方向的镜像平面。

勾选“自动同步”会固定当前范围与方向，编辑源侧后自动更新目标侧。Max 拖动撤销事务未结束时暂缓，松开后同步；每次同步是独立可撤销操作，撤销不会立即被自动同步覆盖。修改方向/范围前先关闭自动同步。关闭工具或切换场景停止监听。此工具用于自由摆放阶段，不修改已固定长度或已添加 IK 的骨架；Skin 权重镜像仍在辅助页独立使用。

## 计算与兼容边界

- 体素模式是本项目的 CPU 内部距离传播实现，参考 Geodesic Voxel 思路，不是 Maya 内置求解器，也不承诺与其数值一致。最长轴 8–64 个体素；需要封闭流形网格；重合接缝顶点在求解时合并。穿出体积的骨段仅使用靠近内部的部分，远处无关骨骼忽略。没有内部骨骼的独立体积使用最近骨骼投影作为源，距离仍只在该体积内部传播。过薄部位、孔洞、自交会给出修复提示，不静默改用线段距离。计算在 Max 主线程进行，大模型需要等待。
- 线段距离计算实际起点、终点及中间位置，不仅使用骨骼枢轴；普通非 Bone 影响使用对象位置。
- Skin 上方自动创建 `LX_Selection` Edit Poly 选择层，仅用来选择/显隐，不应用改变拓扑的操作。已有堆栈顶点数不匹配时拒绝转换。不要手动在该层增删或重排顶点。
- 笔刷以世界空间半径和柔和衰减进行绘制。窄缝、贴近表面可结合“仅选中顶点”和隐藏范围控制绘制区域；笔刷手感、复杂生产角色仍需人工验收。
- 人形模板是可调整 Bone 骨架，不是 Biped/CAT 控制器替代品。通用 Skin 骨骼仍支持原有对象；Biped/CAT 内部层级不由此工具强制改写。

## 批量与分步蒙皮

在模型栏多选目标，骨骼栏可多选限定候选池；未选时从工作集骨骼推断。点击“开始分步蒙皮”，算法为当前模型推荐骨骼，此时不会修改 Skin。调整骨骼栏多选后点“确认此模型并下一步”，逐模型处理；支持跳过、停止、失败后修改参数再重试。自动批量模式无需逐步确认，使用同一推荐逻辑；每个模型是独立撤销事务。推荐基于模型表面采样与骨段距离，并非语义识别，复杂衣物请用分步模式检查。

“选出所选模型的影响骨骼”读取多个模型 Skin 影响的并集，在骨骼栏选中。“仅当前选中骨骼影响”作用于模型栏所选模型全部顶点：移除未选骨骼权重，再归一化；原来不受任何保留骨骼影响的顶点交给最近的保留骨骼。遇到未选且锁定的非零影响会阻止操作，避免覆盖锁定规则。

权重页默认持续显示多选骨骼合计的蓝到红颜色，多个选中模型可同时显示；笔刷过程中更新。此视口覆盖不修改材质、顶点色或渲染设置。栏目影响值为所选顶点均值（没选点时为全模型均值），骨骼栏跨模型显示各模型均值的平均；顶点表显示前 200 个所选顶点（每模型）。颜色开关可随时关闭。关闭工具或切换场景会清除覆盖。

点、面循环和环形使用 Max Graphite 选择，在规则四边形拓扑上选相邻两个种子确定方向；不规则极点不能保证延续成完整环。混合模式采用 Max Multi 预选，按鼠标靠近的点、边、面自动切换，不必手动切页；“转换为 Skin 顶点”将当前类型选区转换用于权重。

[Graphite 循环与环形接口](https://help.autodesk.com/cloudhelp/2024/ENU/MAXScript-Help/files/3ds-Max-Objects-and-Interfaces/Editable-Meshes-Splines-Patches/Editable_Poly/PolyTools-Interfaces/GUID-D5CB1C50-7CB5-4ADB-BDC3-B7E2A88A192D.html)

同一个安装目录的快照更新后，再次呼出工具会检查源码摘要并重载实现，保留场景和权重撤销历史；笔刷笔划尚未结束时会要求先结束绘制。不同安装路径的版本切换仍需重新启动 Max。

窗口缩放不再反向修改左栏高度；模型与骨骼列表自身滚动，外层不叠加滚动容器。权重预览仅在目标、影响骨骼、工具操作或权重撤销版本等发生变化时重读，空闲不重复遍历权重；拖动窗口尺寸期间暂停覆盖绘制，停止后恢复。直接在 Max 原生 Skin 修改权重或子对象选择后，可点击读取 Skin 当前选择 / 刷新更新数值。
