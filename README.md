# 3ds Max Script Collection

这是一个面向 3ds Max 的脚本集合，主要用于常见的建模、动画、骨骼处理与关键帧编辑工作流。

这些脚本都以 MaxScript 形式编写，通常直接拖入 3ds Max 视口或通过“脚本 → 运行脚本”执行即可。

## 目录

- 按材质ID拆分模型.ms
- 保持位移建立父子.ms
- 动画烘焙工具.ms
- 清理根骨骼.ms
- 自定义公式关键帧.ms
- PMX导入.ms
- 模板.ms

## 脚本说明

### 1. 按材质ID拆分模型
功能：
- 选择一个几何体对象
- 按材质 ID 将面拆分为多个新对象
- 新对象命名为对应材质名称
- 可选择保留源对象或删除源对象
- 可选择是否复制对应材质

适用场景：
- 模型分部导出
- 统一材质拆分
- 物件分包处理

### 2. 保持位移建立父子
功能：
- 选择子物体和父物体
- 记录子物体在指定帧范围内的世界变换
- 建立父子关系后，逐帧写回原始位移与旋转
- 以确保“父子绑定后位移保持不变”

适用场景：
- 绑定前后位移保持
- 动画层级调整
- 比如在骨骼或控制器替换时保持动作

### 3. 动画烘焙工具
功能：
- 选择目标对象
- 选择烘焙通道：位置、旋转、缩放
- 指定起止帧和采样间隔
- 将动画逐帧写回为关键帧

适用场景：
- 规范动画数据
- 统一动画采样
- 给导出或后期处理做准备

### 4. 清理根骨骼
功能：
- 自动寻找 Bip001 等根骨骼
- 选择一个虚拟体（Dummy）
- 将根骨骼在指定轴向上的位移烘焙给虚拟体
- 用于简化根骨骼约束或清理绑定结构

适用场景：
- 根运动处理
- 骨骼动画导出前整理
- 运动约束转移

### 5. 自定义公式关键帧
功能：
- 在曲线编辑器中选中关键帧
- 使用变量 v、t、n 进行公式计算
- 支持常见数学运算与函数
- 可应用于旋转、位移等关键帧值

常见变量：
- v：当前关键帧值
- t：当前帧号
- n：物体名称中的后缀数字

示例：
- v * (1 + sin(t * 5))
- v + n * 10
- mod (v + t * 3) 360

适用场景：
- 关键帧波动控制
- 动画修正
- 参数化动画处理

### 6. PMX导入
功能：
- 用于 PMX 相关模型导入流程
- 适合在 3ds Max 中处理 PMX 资源导入与后续整理

### 7. 模板
功能：
- 提供一个通用脚本模板
- 可用于快速开发新工具
- 包含常见 UI、帧范围、执行按钮和图片展示结构

## 使用方法

1. 打开 3ds Max。
2. 任选一个 .ms 脚本文件。
3. 方式一：拖入 3ds Max 视口执行。
4. 方式二：在 3ds Max 中选择“脚本 → 运行脚本”，打开对应 .ms 文件。
5. 按脚本界面提示操作即可。

## 注意事项

- 脚本依赖 3ds Max 的 MaxScript 环境。
- 部分脚本在 UI 中会读取同目录下的 Nahida.jpg 作为背景图；如果图片不存在，不会影响核心功能。
- 执行前建议先备份场景。
- 动画相关脚本会修改关键帧和场景对象，建议在测试文件中先验证。

## 适用场景概览

- 模型拆分：按材质 ID 拆分模型
- 绑定修正：保持位移建立父子
- 动画整理：动画烘焙工具
- 骨骼处理：清理根骨骼
- 曲线调节：自定义公式关键帧

## 维护建议

- 新增脚本时，最好保留统一的注释头和 UI 结构。
- 复杂脚本建议增加日志输出和错误提示。
- 可将通用逻辑抽离为工具函数，减少重复开发。
